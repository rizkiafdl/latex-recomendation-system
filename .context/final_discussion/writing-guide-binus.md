# BINUS Thesis Writing Guide
Source: *Petunjuk Penulisan Laporan Skripsi*, BINUS Business School Undergraduate Program (Rev. 17 Februari 2020)

---

## 1. Page Format

| Setting | Value |
|---|---|
| Paper | A4 (80 gr), double-sided from BAB 1 to appendix |
| Margin left | 4 cm |
| Margin right / top / bottom | 2.5 cm |
| Font | Times New Roman 12pt |
| Line spacing | 1.5 spasi |
| Alignment | Justified (rata kanan-kiri) |

**Font sizes by element:**
- Chapter title (`BAB n`): 12pt, Bold, ALL CAPS, centered
- Sub-section heading: 12pt, Bold, Title Case, left-aligned
- Body text: 12pt
- Table caption / figure caption: 12pt

**Font style rules:**
- *Italic*: foreign words, unfamiliar terms, book/journal/magazine titles in references
- **Bold**: chapter titles, sub-section headings, key terms being emphasized

---

## 2. Spacing Rules

| Between | Spacing |
|---|---|
| Abstract title → abstract body | 2 spasi |
| Abstract body → keywords | 1 spasi |
| Abstract body (internal) | 1 spasi |
| Chapter title → first sub-section | 2 spasi |
| Sub-section title → body text | 1 spasi |
| Body text ↔ table or figure | 2 spasi (both above and below) |

---

## 3. Page Numbering

- **Front matter** (cover to Daftar Lampiran): lowercase Roman numerals `i, ii, iii, …`, centered at bottom (2.5 cm from bottom). Cover page has no number.
- **Body chapters + back matter**: Arabic numerals.
  - Odd pages: number at top-right.
  - Even pages: number at top-left.
  - Chapter opening page: number centered at bottom (1.5 cm from bottom).
- Each chapter starts on an odd page; if the previous chapter ends on an odd page, leave one blank even page.

---

## 4. Thesis Structure (Skripsi Penelitian / Internship Penelitian)

### Front Matter (Roman numerals)
1. Halaman Sampul
2. Halaman Judul
3. Halaman Pernyataan Orisinalitas (softcover) / Persetujuan Dosen Pembimbing (hardcover)
4. Halaman Pernyataan Dewan Penguji (hardcover only)
5. Halaman Persetujuan Publikasi Skripsi (hardcover only)
6. Abstrak (bilingual: English above, Indonesian below; 1 page; 100–200 words per language)
7. Kata Pengantar
8. Daftar Isi
9. Daftar Tabel
10. Daftar Gambar
11. Daftar Lampiran

### Body Chapters (Arabic numerals)
| Chapter | Title | Key Contents |
|---|---|---|
| BAB 1 | Pendahuluan | Latar Belakang Masalah, Rumusan Masalah (pointer, kalimat tanya), Tujuan dan Manfaat, Ruang Lingkup |
| BAB 2 | Landasan Teori dan Kerangka Pemikiran | Grand/Middle/Applied Theory (≥10 buku, ≤10 tahun terakhir), Penelitian Terdahulu (≥5 jurnal, ≥3 internasional, ≤5 tahun terakhir), Kerangka Pemikiran |
| BAB 3 | Metodologi Penelitian | Desain Penelitian, Operasionalisasi Variabel, Jenis & Sumber Data, Metode Pengumpulan Data, Metode Sampling, Hipotesis (jika ada), Metode Analisis |
| BAB 4 | Hasil dan Bahasan | Profil Perusahaan, Profil Responden, Analisis Data, Implikasi Hasil |
| BAB 5 | Simpulan dan Saran | Simpulan (jawaban dari Rumusan Masalah, pointer), Saran (spesifik & actionable, pointer) |

### Back Matter (continues Arabic numbering)
- Referensi
- Lampiran (numbered with Arabic numerals, include kuesioner / wawancara / tabulasi)
- Riwayat Hidup
- Indeks/Glossary (if any)

---

## 5. Table Rules

- Caption **above** the table: `Tabel X.Y Judul Tabel` (Title Case, no symbols)
- Caption must be on the same page as the table
- Table must not be split across pages unless unavoidable; if split, repeat the header row and caption notation on the next page
- If table exceeds half a page, place it on its own page
- Only horizontal lines (row rules) visible — no vertical column borders
- 2-spasi gap between table/figure and surrounding body text

---

## 6. Figure Rules

- Caption **below** the figure: `Gambar X.Y Judul Gambar`
- Same spacing and placement rules as tables
- Source must be cited if figure comes from an external reference

---

## 7. Citation Style (APA, in-text)

- No footnotes for publication references — use in-text citations only
- Format: `(LastName, Year)` or `(LastName, Year: page)` for direct quotes
- Can appear at start or end of a paragraph
- **Direct quote (≤3 lines / 40 words)**: integrate into paragraph with quotation marks + `(LastName, Year: page)`
- **Direct quote (>3 lines)**: set off from paragraph as a separate indented block
- **Indirect quote / paraphrase**: no quotation marks, `(LastName, Year)`
- `et al.` only when ≥6 authors

---

## 8. Reference List Style (APA)

General order: Author (Year). *Title*. City: Publisher.

| Source type | Format |
|---|---|
| Book | `LastName, I. (Year). *Title*. City: Publisher.` |
| Book chapter (with editor) | `LastName, I. (Year). Chapter title in Editor (Ed.) *Book Title*, pp. City: Publisher.` |
| Journal article | `LastName, I. (Year). Article title. *Journal Name*, volume(issue), pages.` |
| Magazine/Newspaper | `LastName, I. (Date Month Year). Article title. *Publication Name*, pages.` |
| Institutional author | `[Acronym] Full Institution Name. (Year). *Title*. City: Publisher.` |
| Thesis/Dissertation | `LastName, I. (Year). *Thesis title*. Skripsi S1/Tesis S2. Universitas, City.` |
| Online journal article | `LastName, I. (Year). Article title. *Journal Name*, volume(issue), pages. (Online). Diakses DD Bulan YYYY dari http://...` |

**Rules:**
- All authors must be listed (no truncation for reference list)
- Author format: `LastName, Initials.`
- References only for works actually cited in the text
- Sorted alphabetically by first author's last name
- Section heading: `REFERENSI` (12pt, Bold, ALL CAPS, centered)

---

## 9. Abstrak Format

- One page total, bilingual: **ABSTRACT** (English) on top, **ABSTRAK** (Indonesian) below
- Each 100–200 words, written in one paragraph
- Structure per paragraph: Tujuan → Metode → Analisis → Hasil → Simpulan
- End with author initials in parentheses, e.g., `(M.R.A.)`
- Keywords: 3–5 terms taken from title and body; line label `Kata Kunci:` / `Keywords:`
- Title of thesis written in italic for the English version

---

## 10. Prohibited Formatting

- No blank pages except at the end of a chapter (to force odd-page start)
- No extra spaces between words to justify right margin
- No chapter/sub-section title, sub-heading, or table caption at the very bottom of a page (must flow to next page)
- No symbols (`&`, `/`, `@`, etc.) in the thesis title

---

## 11. Academic Ethics

- Direct and indirect quotations must always cite the source
- Images/figures from external sources must cite origin
- Plagiarism (dominant portion from another work, or intentional omission of source) → academic sanction per BINUS regulation 1426/SK/PTTKK/UBN/VII/2016

## Quick Reference: What Goes Where

| Item | Location | Numbering |
|---|---|---|
| Cover | Front matter | No number |
| Abstrak | Front matter | Roman (e.g., iv) |
| BAB 1–5 | Body | Arabic (1, 2, 3…) |
| Referensi | Back matter | Continues from body |
| Lampiran | Back matter | Continues; each item labeled Lampiran 1, 2… |
| Riwayat Hidup | Back matter | Continues |
